# Frustration gesture style frames

Four key frames generated with the Recraft vector model through OpenRouter (prompts beside each file) on 16 October 2026, in the Tokyo Night colours, as style references for illustrated cursor gestures. Rage click and backtrack set the character: a pointer with arms and legs, flat lavender body, one accent per gesture, controls as dark slabs. Hesitation and long pause do not hold that character.
