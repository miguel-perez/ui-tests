# Frustration gesture style frames

Four key frames generated with the Recraft vector model through OpenRouter (prompts beside each file) on 16 October 2026, in the Tokyo Night colours, as style references for the illustrated hero gestures. Rage click and backtrack set the character: a pointer with arms and legs, flat lavender body, one accent per gesture, controls as dark slabs. Hesitation and long pause lost the character and are kept only for the record. The animated gestures on the site are drawn from this direction in `apps/web/components/hero-motion.tsx`.
