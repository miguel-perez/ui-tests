Your server, one command.

The consent, the questions, the collector and the report run on a ui-tests server you start for as long as a study is open: on your laptop, a machine you rent or a free tier. Nobody else runs it, and the recordings stay on your box. npx ui-tests host, one command that puts it in an account you own, is not shipped yet.

The command

On any machine with Node 24 or later, with UI_TESTS_PUBLIC_URL set to the address people reach it at. It prints that address and the tag that points there. The Docker image, to be published as ghcr.io/miguel-perez/ui-tests, is built from the repository and runs the same thing.

TerminalExample
$ npx ui-tests serve ui-tests server: https://tests.weekboard.example <script data-ui-tests="https://tests.weekboard.example">…</script>

The line

One inline script tag in your HTML layout, whatever your app is built with. It does nothing until a person is in an attempt: no request, no change to the page.

index.htmlor your layout
<script data-ui-tests="https://tests.weekboard.example">(function(){try{var d=document,u=d.currentScript&&d.currentScript.getAttribute('data-ui-tests')||'';if(!/^https?:\/\/[^/?#\s]+\/?$/i.test(u))return;u=new URL(u).origin;var l=location,m=/(^#|&)ui-tests=([^&]*)/.exec(l.hash);if(m){var h=l.hash.replace(m[0],m[1]=='#'?'#':'').replace('#&','#');history.replaceState(history.state,'',l.href.split('#')[0]+(h=='#'?'':h))}else{var j=JSON.parse(localStorage.getItem('ui-tests-attempt'));if(!j||j.server!==u||!(j.expiresAt>Date.now()))return}var s=d.createElement('script');s.type='module';s.src=u+'/ui-tests.js'+(m?'#'+m[2]:'');d.head.appendChild(s)}catch(e){}})()</script>
