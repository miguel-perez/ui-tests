# How analysis and labelling tools show sessions, results and dashboards

16 October 2026. Audit of NVivo, ATLAS.ti, MAXQDA, Dovetail, Condens, Marvin, Lookback, Grain, Label Studio, Prodigy, Maze and UserTesting, reduced to the conventions the results views follow.

From NVivo, ATLAS.ti, MAXQDA, Dovetail, Condens, Marvin, Lookback, Grain, Label Studio, Prodigy, Maze and UserTesting (October 2026). These are the shapes the readers already know; the three results views follow them.

1. **One session: video top-left, transcript or timeline right, a horizontal scrubber under the player with coloured bands.** Every tool with media puts the recording beside the transcript and a scrub line beneath. Tagged moments appear twice: as thin coloured bars stacked under the timeline (MAXQDA's coded-segment strip, NVivo stripes, Label Studio region lanes) and in the text as colour-tinted runs with a small chip. One kind of moment, one colour (deviation blue, dead click and give-up in the dead colour, pause yellow, done teal); these are signal colours for moments, distinct from the outcome colours in rule 5. A hovered band tints its matching run. Metadata as a row of fields above the player: participant, date, duration, device, task; notes and words in a time-ordered feed that seeks on click.
2. **Across people: a moment-by-participant matrix with count cells, and a ranked bar list.** NVivo's matrix query, MAXQDA's Code Matrix Browser, ATLAS.ti's Code-Document table and the Dovetail, Condens and Marvin charts all reduce to tags as rows, participants as columns, counts or sized squares in cells, bars for ranking. Every cell and bar opens the evidence moments (quote, participant, timestamp, play). Severity is a separate small chip (Maze's bands: rework for scores below 50, check for 50 up to but not including 80, great for 80 to 100), never an overloaded tag colour.
3. **Findings as cards with embedded evidence.** Dovetail docs, Condens artifacts, Marvin insights and Lookback findings: one headline, a short summary, then the evidence clips as quote, participant and timestamp, each playable, with a count ("6 of 8 participants") and a severity chip; the jump-to-source affordance always visible. This is the pull-request example's findings list.
4. **Dashboard: a plain table, not tiles.** Condens's sessions list, Maze's responses, Label Studio's project progress, Grain's library: one row per run with name, date, participants (count or avatars), status as a muted chip (draft, running, done), one headline metric with its band colour, last activity; a thin progress bar per row only where runs have states.
5. **Colour discipline: light neutral chrome, colour reserved for the data.** All of these tools default to light UI; chrome is white and grey with one brand accent; codes and tags carry a small categorical palette that stripes, text tints and chart bars inherit; uncoded and empty in grey; green and red only for outcomes (a correct or incorrect run result), while moments keep their own signal colours from rule 1. So the product surfaces are mostly white, with four to six saturated signal colours doing all the work.
